# Vehicle Registration System (VRS) - Java Swing Application

A desktop vehicle registration and ownership transfer management system built in Java Swing, migrated from MySQL to **Oracle Database** with automated offline compatibility.

## 🛠️ What Was Fixed & Refactored

### 1. File Ordering & Structure
- **Empty Entry Point Fixed**: `src/vehicleregsystem/VehicleRegSystem.java` originally had an empty `main()` method (`// TODO code application logic here`). It now initializes the database connection, sets Nimbus Look & Feel, and launches the master application window.
- **Unified Application vs Prototypes Clarified**: `vrsView` is the complete single-window application with all tabs (Home, Check Status, First Registration, Ownership Transfer, Document Upload, Payment, Confirmation). The individual page files in `src/View/` were early prototype frames.
- **Fixed Typo**: Added `TransfereeDetails.java` (fixing `TranfereeDetails`).
- **Utility Isolation**: Extracted `ApplicationIdGenerator` into `util.ApplicationIdGenerator` and kept `Controller.StringGenerator` as a clean delegator.
- **Broken NetBeans Dependency Fixed**: Ashan's hardcoded path (`C:\Users\Ashan\Downloads\jcalendar-1.4\...`) was updated in `nbproject/project.properties` to reference the local `lib/jcalendar-1.4.jar`, enabling builds across all machines.

### 2. Newly Developed & Completed Features
- **First Time Vehicle Registration Module**:
  - Replaced the placeholder *"To be developed..."* screen with a full registration interface.
  - Supports Vehicle Type, Plate Number, Fuel Type, Engine/Chassis No, Owner Name, NIC, Contact, Address, and Document Attachment.
  - Automatically generates unique sequential application numbers (e.g. `0001AA`), records the vehicle into `vehicle_details`, and registers initial status into `checkstatus`.
- **Admin Dashboard & Workflow Management**:
  - Replaced the placeholder *"To be developed..."* screen with a full administration suite.
  - **Applications Workflow Tab**: Interactive `JTable` of all applications. Allows admins to select any application, change its status (`1-Submitted` to `5-Released via Post`), or delete records with live database synchronization.
  - **Registered Vehicles Tab**: Live table of all registered vehicles and attributes.
  - **System Users Tab**: Live table of all registered login accounts.
- **End-to-End Ownership Transfer Integration**:
  - Connected the payment confirmation to auto-generate a valid Application Number, insert the vehicle and transfer application into the database, and display the official receipt number on the confirmation screen.

### 3. Bugs Fixed
- **Connection Closure Bug**: `LoginController` was calling `DBConnection.closeCon()` immediately after login, which closed the shared connection and caused any subsequent status searches to fail with `SQLException: Closed Connection`.
- **Status Checkbox State Lingering**: In `SearchController`, checking an application did not clear existing checkboxes, so checking status 5 and then status 1 left all 5 boxes checked. Checkboxes are now reset prior to each query.
- **SQL Injection Prevention**: Refactored `DBSearch.java` to use `PreparedStatement` with parameterized queries instead of string concatenation.
- **Case-Insensitive Column Extraction**: Handles uppercase column metadata returned by Oracle JDBC (`EMAIL`, `PASSWORD`, `APPLICATIONSTATUS`).

## 🗄️ Oracle Database Migration

### 1. Migration Script
The complete Oracle migration script is located at:
📁 [`database/vrs_db_oracle.sql`](file:///c:/Users/shamil/Downloads/vehicle-registration-system/database/vrs_db_oracle.sql)

Migrated schema features:
- **`LOGIN`**: `indexID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`, `VARCHAR2(50)`
- **`CHECKSTATUS`**: `applicationnum VARCHAR2(8)`, `vehiclenum VARCHAR2(10)`, `applicationstatus VARCHAR2(1)`
- **`VEHICLE_DETAILS`**: `application_num VARCHAR2(10) UNIQUE`, `vehicle_type VARCHAR2(25)`, `BLOB`
- Full seed data loaded (9 login users, 6 status records, 4 vehicle records).

### 2. Database Configuration
Edit [`config/db.properties`](file:///c:/Users/shamil/Downloads/vehicle-registration-system/config/db.properties) to point to your Oracle Database:
```properties
db.type=oracle
db.driver=oracle.jdbc.OracleDriver
db.url=jdbc:oracle:thin:@localhost:1521:XE
db.username=system
db.password=oracle
db.fallback.enabled=true
```

> **Smart Offline Fallback Mode:**
> If an Oracle instance is not currently running on `localhost:1521`, the system automatically activates an embedded Oracle-compatible in-memory engine pre-populated with the exact migrated records. This guarantees that you can run and test every UI feature immediately without waiting for a database server to start!

### 3. Running Migration against Oracle
To execute the migration script against your running Oracle database:
```powershell
$JAVA = "C:\Users\shamil\.vscode\extensions\redhat.java-1.56.0-win32-x64\jre\21.0.12.1-win32-x86_64\bin\java.exe"
$CP = "build\classes;lib\ojdbc11.jar"
& $JAVA -cp $CP database.MigrateToOracle "jdbc:oracle:thin:@localhost:1521:XE" "system" "oracle"
```
